# KMU-v2 Context Pack

Paket ini merangkum konteks proyek untuk melanjutkan pekerjaan di chat/akun lain. Mulai dari `CURRENT_STATE.md`, lalu baca `DECISIONS.md` dan `NEXT_STEPS.md`.

Paket ini hanya berisi dokumentasi. Jangan mengirim `.env`, database `kec_magelang`, dokumen warga, atau file upload ke akun/chat lain.

Sumber yang harus dianggap paling akurat: kode dan migrasi pada checkout proyek yang sedang dipakai, lalu dokumentasi ini. Percakapan lama membantu memahami alasan keputusan, tetapi dapat tertinggal dari repo.
